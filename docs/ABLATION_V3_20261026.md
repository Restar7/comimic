## 1. 可复用（**不重跑**，直接引用）

| 编号 | 旧结论 | 为什么可复用 |
|---|---|---|
| **N2** | FM 反传 4 后端：`pathwise` 保真最好（token 0.1149）、`adjoint` reward 齐平但 token 略差（0.1213）、`truncated` **有偏**（token 反升 0.1740）、`checkpointed` 同墙钟少 1/3 步 | 这是"梯度穿过 K 步采样"的**数值性质**，与 token 语义无关 ⇒ **直接选 `pathwise`**，不再扫 |

## 2. 要跑的格子

### N0 · BC 对照臂（`λ_r = 0`）——**所有其它格子的分母**

```bash
LAMBDA_R=0 RUN=s3_n0_bc ONLY_BC=1 bash scripts/launch_joint_ha_v2.sh
```
- 目的：只训 FM-BC（奖励路径关闭），得到"不做奖励反传"的基线；
- 判据：其它格必须**相对它**才有意义；
- 成本：2 卡 × 2000 步 ≈ 1.5 h。

### N1 · 奖励反传（主结果，扫 `λ_r`）

```bash
for LR in 0.1 0.3 1.0; do LAMBDA_R=$LR RUN=s3_n1_lamr$LR bash scripts/launch_joint_ha_v2.sh; done
```
- 每 50 步看 `grad_ratio = ‖∇L_r‖/‖∇L_fm‖`，目标区间 **0.1–0.5**（偏了就调 `λ_r`，别动别的）；
- **判据**：闭环成功率（6 任务 × 3 seeds）相对 N0 **不降**，且（摔倒率↓ / 到目标距离↓ / 抓取手闭合↑）至少一项显著改善；
- 若全部与 N0 持平或更差 ⇒ 结论就是"**奖励反传无增益**"，如实写；
- 成本：3 格 × 1.5 h ≈ 4.5 h（卡紧可先跑 1.0 一格定性）。

### N3 · horizon（等**墙钟**，不是等步数）

```bash
H=8  STEPS=3000 RUN=s3_n3_h8  bash scripts/launch_joint_ha_v2.sh
H=16 STEPS=3000 RUN=s3_n3_h16 bash scripts/launch_joint_ha_v2.sh
```
- 两个格子**同墙钟**（比如各 45 min），记录各自完成的步数；
- 判据：闭环成功率（首选）+ 想象回报（参考）；
- 成本：2 卡 × 2 壁钟块 ≈ 1.5 h。
- 注意：H=16 是为覆盖"闭环每 12 步重取 chunk"的执行段；若 H8 明显更好则改回 H8，并在文档里写明执行段覆盖不足的代价。

### N6 · 共同适配（旧的 A5 重做，**小 lr 解冻 WBC**）

```bash
WBC_LR=1e-6 LAMBDA_R=0.3 RUN=s3_n6_coadapt bash scripts/launch_joint_ha_v2.sh
```
- 与 N1 唯一差别：WBC 用**小 lr** 一起更新（不是从头训），WM 仍冻结；
- **成对交付**：结束后闭环/A1 表必须用**更新后的 WBC**；并**重跑** HA-699 与 BONES-500；
- 每 500 步记副作用：新 WBC 的 `joint_rmse`、`n_failed`、WM `qd_corr`；出现"闭环没升但保真度掉" ⇒ 判**模型利用**，不计增益；
- 成本：2 卡 × 1.5 h + 门禁 0.5 h。
- 历史依据（仅作参考、不作结论）：旧 A5 同配置下 `token_mse 0.3721→0.1161`，但 `hand_mse 0.0083→0.0235`（**指标互挖**，所以必须用闭环判）。

### N4 · WM 速度重标定（**前置依赖**，先跑它）

```bash
# 1) 对 WBC_v2 重标定（只动 WM，不动 policy）
python3 scripts/finetune_wm_velocity_policy.py \
  --ckpt runs/wbc_v2_label/wbc_v2.pt --out runs/wbc_v2_label/wbc_v2_wmvel.pt --steps 800
# 2) 门禁
python3 scripts/eval_wm_velocity.py --ckpt runs/wbc_v2_label/wbc_v2_wmvel.pt --tokens label
```
- 现状：未标定的 `qd_corr 0.154 / ratio 2.79`；800 步后应到 **`qd_corr ≥0.74`、`ratio ∈[0.9,1.1]`**（v1 同仪器 0.737/0.947）；
- 判据：不过标定 ⇒ **N0/N1 的奖励信号不可信**，不许开跑；
- 成本：单卡 ~10 min。
