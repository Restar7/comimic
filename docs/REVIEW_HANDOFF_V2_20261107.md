## 0. 一句话

冻结的 VLA 输出 64 维 motion token，我们在 token 上加一个小残差 Δ（"Δtoken"），
Δ 由**世界模型反传得到的教师标签**监督训练。**教师方向已被真机（Isaac）验证可用（0.66–0.69）**，
但**部署幅度是验证尺度的 ~10 倍、且 WM 高估改善 2–3 倍**；闭环 18 对配对**没有成功率收益**。

## 1. 系统与部署链路

```
相机 (ego view 256×256) + state46
        │
        ▼
GR00T N1.7 = Cosmos-Reason2-2B backbone (frozen) + 1.09B DiT action head (fine-tuned)
        │   64 维 motion token chunk (T=40 @ 50 Hz = 0.8 s)
        ▼
   token' = token + Δ            ← 唯一被训练的模块（Δtoken）
        │
        ▼
SONIC decoder (ONNX, CPU EP)  → 29 关节目标 (50 Hz)
        │
        ▼
Isaac / 真机
```

* **推理时不含世界模型**；WM 只在离线采标签/诊断时用。
* 闭环一个 chunk ≈ 2.6 s；一次完整评测 = 3 任务 × 6 seed × 3000 步 ≈ **3 h**。

## 3. 教师标签的数学定义

```
ε  = 共享扰动 (64)   或  逐帧 Δ_t (64)
token'_t = token_t + ε
a_t      = SONIC(token'_t, obs_t)        (冻结)
s_{t+1}  = WM(s_t, a_t, ξ)               (冻结)
J_H      = Σ_{t<H} γ^t · survival_t · r_t
g        = dJ_H/dε                       (autograd，一次 20 步反传)
```

单条成本（实测）：H=20 **1869 ms**、H=10 987 ms、H=5 439 ms、H=2 231 ms、纯前向 88 ms。

## 4. 实测结果（口径都注明）

### 4.1 【核心】教师方向在真机上的验收（Isaac，32 窗口，H=20）

做法：从真实窗口取 `s₀`，教师给出修正后的动作序列；真物理滚 20 步，用**同一个 reward** 结算，
两臂 = 「修正」vs「不修正」。

**用正确 WM（`wm_gain2.pt`，= 标签口径）：**

| 教师 | 符号一致率 | **ΔJ 相关** | **真物理变好比例** | \|ΔJ_true\| 中位 | \|ΔJ_WM\| 中位 |
|---|---|---|---|---|---|
| **单次梯度（η=0.15，= 标签公式）** | **0.688** | **+0.472** | **0.688** | 0.0503 | 0.0942 |
| WM 内 20 步优化（§6） | 0.656 | +0.525 | 0.656 | 0.0529 | 0.1744 |

判据：≥0.65 = 方向可用。
⇒ **标签方向可用**；**多步优化没有更好**（0.656 vs 0.688，n=32，差在噪声内）。
⇒ **WM 高估改善**：`|ΔJ_WM|/|ΔJ_true|` = **1.9×（单次梯度）/ 3.3×（多步）**。

历史另一次真值探针（用 `wm_a24_k20.pt`，δ=0.03，动作空间 ±）：H=2 符号 1.000/ΔJ corr +0.964/幅值 1.14×；
H=20 符号 0.984/ΔJ corr +0.092/幅值 1.79×。**⚠️ 它用的不是标签那个 WM，不能与上表直接合并。**

### 4.2 标签可学性（ridge/MLP，`labels_v3`，只在非零标签帧算 cos）

特征 = `token_chunk(2400) + obs_deploy930(930) + state64(64)`；留出 = 族内留 30% 运动。

| 目标 | 视界 | 平均 cos（4 族） |
|---|---|---|
| token 逐帧 (64×40) | 20 | **0.313** |
| token 共享 (64) | 20 | **0.411** |
| token 逐帧（只第 0 帧） | 1 | 0.508 |
| 动作共享 (29) `g1` | **1** | 0.505 |

留族 vs 留运动（逐帧 20 步）：加权 **0.301** vs **0.341**（double_desk 0.344/0.402，open_door 0.314/0.319，
sit_sofa 0.297/0.322，vision_navi 0.220/0.290）⇒ 任务覆盖只值 0.04。

### 4.3 视界 H 曲线（512 窗口，窗口级梯度，K=20）

### 4.4 架构消融（5 臂，38,400 标签，masked cos，留出 double_desk）

B1 常数 **0.165** / B2 逐帧模板 **0.176** / B3 flat **0.299** / **B4 temporal 0.371** / B5 打乱历史 **0.337**
⇒ 条件化真实、架构有用（+0.07）、历史有用（+0.03），但全部停在 0.37–0.41。
（对照：v5 头 0.397、ridge 0.376、MLP 0.412）

### 4.7 闭环 A/B（36 集，3000 步，带视频与逐步 dump）

3 任务（OpenDoor / SitSofa / VisionNavi）× 6 seed，同 seed 同目标同初值。

| 指标 | base | delta（S 臂，cos 0.459） | 统计 |
|---|---|---|---|
| 成功率 | **11/18 = 61.1%** | **9/18 = 50.0%** | McNemar p=**0.625**；配对差 95% CI [−11,+33] 个点 |
| root 漂移 p50 | 0.48 / 0.44 / 1.02 m | 0.48 / 0.32 / 1.33 m | 配对中位 +0.029 m，p=0.41 |
| body 漂移 p50 | 0.483 / 0.427 / 1.015 m | 0.492 / 0.317 / 1.315 m | 配对中位 +0.034 m，p=0.24 |
| **站桩占比** | 0.24 / 0.30 / 0.24 | 0.34 / 0.40 / 0.31 | **13/18 变高，p=0.048** |

* **漂移 = 整体平移/航向错，不是姿势错**：14 个 body 的漂移 p50 全在 0.62–0.68 m，

* 漂移随时间单调累积：VisionNavi base 0.22 m（0–300 步）→ 1.18（600–1200）→ 1.23（1200+）。
* 参考 = 该任务 100 条示教的逐帧 body 中位数；**示教第 0 帧 root 与 env reset 逐位一致**（3 任务都验过）。

## 6. WM 内受约束轨迹优化教师（`scripts/opt_teacher_wm.py`）

* 每窗口一个可训练 `U (40×64)`，`Δ = cap·tanh(U)·mask(t<20)`，`cap=0.08`；
* 冻结链 `token → SONIC → WM → reward`，N 步 Adam（`lr 0.05`）；
* 约束：动作空间信任域 **0.03**（= 真值探针验证尺度）、峰值/变化率（**用均方，不用 sqrt**，
  否则 0 处导数 ∞ × relu 零梯度 = NaN）、状态可行性（骨盆高度、R22=cos tilt）；
* 三个 NaN 源已定位并修：`u·(c/‖u‖)` 在 0 处导数 8e10；`sqrt` 在 0 处；WM 状态通道 inf/nan；
* 结果：**WM 收益绝对值更低**（+0.035~0.041 vs 单次 +0.063~0.072），但**单位动作收益高 1.4–2.3×**；
  **真机验收 0.656 < 0.688** ⇒ 多步优化没有换来真机改善。

## 7. ⚠️ 已作废、不可再引用的结论（我此前说错的）

1. **"H=20 方向只有 +0.092 相关"** —— 错。+0.092 是 **ΔJ 幅值**相关；符号一致率是 **0.688（本次）/0.984（历史 WM）**。
2. **"动作空间 0.505 是空间优势"** —— 错。`g1` 是 **1 步**奖励梯度；同视界下 token 1 步是 0.508。
3. **"逐帧标签被稀释 2×、5 臂数字作废"** —— 错。`train_distill_temporal.py` 和 `pretrain_v5_supervised.py`
   本来就有 mask；只有 `train_distill_v3.py` 的逐帧路径缺（已修，未影响过已报结论）。
4. **"标签是用 bundle 自带 WM 生成的、那个 WM 的梯度是噪声（0.50–0.56）"** —— 错。
   标签用 `wm_gain2.pt`（A′ 线）；0.50–0.56 是对 bundle 默认 WM 的误测。用正确 WM 重测 = **0.688**。
5. **"可学性 0.41 = 观测信息不足 ⇒ 这条线学不动"** —— **未定论**。该推断建立在若干错诊断上；
   在"教师方向 0.69 可用"的前提下，0.41 更像"学生容量/目标平滑性"问题，需要重新验证。

## 8. 尚未验证（不得声称）

1. **Gate B**：`token ± Δ` 在真机里是否是上升方向 —— 已测的只有**动作空间**（§4.1）。
   token→动作要过 SONIC 解码器（含 80 Hz 策略网络、PD、时延），方向可能被扭曲。
2. **token 空间 ΔJ 配对**：`J_isaac(+Δ) vs J_isaac(0)` 未测。
3. **帧间视觉信息**：视觉探针只用了单帧 + 均值池化。
4. **大样本闭环**：n=18 只能分辨 **>25 个点**；5–10 个点的效应测不出。**建议 48 对起。**
5. **部署状态 OOD**：标签来自示教状态，闭环会漂 0.45–1.3 m；这一条从未量化。
