# 「最优修正到底跟什么有关」：实测结论（2026-11-06 17:00）

> 一句话：**它不是常数**（我之前的假设是错的），它的可预测部分只来自
> **(当前状态, 当前动作)** —— 约占 20~29%；**token / 未来参考 / 历史 / xi 一点都贡献不了**；
> 剩下 ~70% 是 WM 回报面本身的高频噪声。所以"最优修正跟什么有关"的答案是：
> **跟你在奖励面里的位置（状态×动作）有关，跟"未来要做什么"无关。**

## 1. 视界扫掠：任何一个 k 下，最优点都不是常数

`J1_GRAD_PROBE_K=1,2,5,20`，n=256 窗口（batch 256，exc 起点集合），`resid/mean` 用 L2：

| k | mean_l2 | resid_l2 | **resid/mean** | 含义 |
|---|---|---|---|---|
| 1 | 0.0009 | 0.0025 | **2.835** | 单步 ∂r/∂a，最干净的对象，差异仍是均值的 2.8 倍 |
| 2 | 0.0013 | 0.0033 | **2.519** | |
| 5 | 0.0028 | 0.0040 | **1.442** | |
| 20 | 0.0061 | 0.0066 | **1.073** | 20 步的"相干均值"累积变大，但残差仍 > 均值 |

⇒ **"最优点≈常数"这个假设被证伪**（v13 学到的 `resid/mean=0.098` 才是伪影）。
⇒ 也说明 G5 门限"残差/均值 > 0.5"当初是**用常量假设反推出来的**，跟实现难度无关。

## 2. 可预测性：只有 (状态, 动作) 有用，且只有 ~20–29%

`J1_GRAD_DUMP` 落盘 ĝ1 = ∂r_0/∂a_0（(B,29)，**无 Jacobian 连乘**），12 个 batch × 256
= **n=3072**，8 折 CV，标准化 + ridge(lam=10)；MLP = 2×256 GELU（与 delta-token 同量级），
折内再切 10% 早停。

| 特征 | 维度 | ridge R² | ridge relL2 | ridge cos | MLP R² | MLP cos |
|---|---|---|---|---|---|---|
| state（71 维） | 71 | +0.079 | 0.969 | 0.335 | +0.002 | 0.342 |
| **act0（29 维动作）** | 29 | **+0.083** | 0.971 | 0.327 | **+0.121** | 0.370 |
| **state+act0** | 100 | **+0.195** | 0.909 | **0.525** | **+0.285** | **0.567** |
| feats（rot6d+qd 35） | 35 | +0.032 | 0.992 | 0.240 | −0.024 | 0.253 |
| token（64 维命令） | 64 | +0.010 | 0.996 | 0.124 | −0.080 | 0.117 |
| ref0（参考状态） | 71 | +0.026 | 0.992 | 0.181 | −0.156 | 0.160 |
| state+act0+token | 164 | +0.192 | 0.911 | 0.521 | +0.207 | 0.526 |
| all（含 ref/feats） | 270 | +0.202 | 0.901 | 0.543 | +0.138 | 0.506 |

参照：**零预测 R² = −0.005**（⇒ 均值≈0，R²=0 就是"常数基线"），跨样本
`std/|mean| = 1.35`、逐维 `std/|mean| = 12.9`（⇒ 目标确实不是常数）。

三条硬结论：
1. **动作本身是最强的单变量**（cos 0.33 → 与状态联合 0.53）。奖励是 huber 距离 ⇒
   ∂r/∂a 强烈依赖"当前动作"本身，这是几何必然。
2. **token / 未来参考 / 观测历史 / xi 全都解释不了**（cos ≤0.18）。所以
   "把未来要做什么喂给网络"这条路在目标层面就没有信息可喂。
3. 加上 token/ref 后 R² **不涨反跌**（0.195 → 0.202/0.138）⇒ 纯粹是维度噪声。

## 3. 之前"R² 全 ≤0"是**小样本伪影**，须更正

n=256、p=71~1420 时 ridge CV-R² 全为负（−0.17 ~ −0.99）；把 n 提到 3072 后
同一特征的 R² 转正（state+act0: −0.20 → **+0.195**）。
⇒ **结论更正**：不是"没有任何输入能预测 ĝ"，而是"需要 ~3k 样本才测得出来，
且只有 20~29% 可预测"。这条更正也顺带说明：所有基于 n=64 的 R²（−3.6/−7.9）
都是噪声，不能用。

## 4. token 空间的目标（∂J/∂token）——原路线到底有没有可学信息

原路线把 Δ 加在 **64 维 token** 上，所以它该学的目标不是 ∂J/∂A，而是
**∂J/∂token = J_dec^T ĝ**（含 WBC 解码器雅可比）。一次 backward 即得。
n=3072（24 × 128），8 折 CV：

| 目标 | 特征 | ridge R² | ridge cos | MLP R² | MLP cos |
|---|---|---|---|---|---|
| **∂r₀/∂token** | token(64) | +0.029 | 0.194 | −0.069 | 0.175 |
| | **state(71)** | **+0.119** | **0.393** | +0.054 | 0.418 |
| | state+token | +0.125 | 0.395 | +0.016 | 0.399 |
| | act0(29) | +0.087 | 0.320 | +0.111 | 0.373 |
| | **state+act0** | **+0.176** | **0.472** | +0.168 | **0.500** |
| **∂J₂₀/∂token** | token | −0.022 | 0.206 | −0.080 | 0.236 |
| | state | −0.035 | 0.229 | −0.403 | 0.304 |
| | state+token | −0.057 | 0.232 | −0.195 | 0.334 |
| | actH(580) | −0.374 | 0.191 | −0.226 | 0.318 |
| | state+actH(651) | −0.419 | 0.215 | −0.198 | 0.351 |

三条结论（都直接影响怎么改）：
1. **token 自己几乎没信息**（cos 0.19~0.21），**state 才是单变量最强**（单步 0.39）。
   而 Δtoken 现在只吃 `feats`(rot6d+dof_vel 35 维) + token，**没吃 dof_pos / root**。
2. **horizon 越大越不可学**：单步目标 cos 上限 0.47~0.50，20 步只有 0.22~0.35
   （R² 全 ≤0）。⇒ "穿过 20 步反传"本身就在毁信号。
3. 加上 **act0** 后两个空间都涨（A 空间 0.53→0.57，token 空间 0.39→0.47）。

## 5. 原路线还能怎么改（结论：能，且不用换架构）

| # | 改动 | 依据 | 成本 |
|---|---|---|---|
| 1 | **Δtoken 的输入**：35 维 feats → `state71 + act0(29) + token64` | token 单独 cos 0.19 vs state+act0 0.47~0.57 | 服务端两趟解码（base token → a_base → Δ → 再解码）；VLA 只跑一遍 |
| 2 | **horizon**：20 步反传 → **1~3 步**（或分步权重 1, 0.5, 0.25…） | 20 步目标 cos ≤0.35、R²≤0；单步 0.47~0.50 | 改一个权重向量 |
| 3 | **稠密监督**：加 `‖Δ − η·norm(ĝ)‖²`（ĝ 一次 autograd 即得），奖励项降权 | 现目标 70% 是噪声，参数空间梯度只剩相干项=常向量 | 已有探针代码可复用 |
| 4 | **幅度**：用探针 `‖Δa‖/η` 标定（目标 ≤1.5η，v10 的 2.65η 已判死） | 信任域在 token 空间没有物理尺度 | 已有 `apply_norm_cap` |

**上限要老实说**：即使 1~4 全做完，可学部分 ≈ cos 0.50（token 空间），
70% 的跨样本变化取不回来；能不能换成成功率，只能靠闭环实测（v13 现在是 base 的 0.53 倍）。
