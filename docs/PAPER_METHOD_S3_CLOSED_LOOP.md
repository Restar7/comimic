## 2. 闭环：**每轮 10 个主阶段 + 可选 8.5 执行器适配**

每轮严格按序执行 10 个主阶段；每个阶段把产物写入 `runs/S3_pipeline/<ROUND>/state.json`，
**上一阶段产物缺失或校验不过就不许往下跑**。平台按多轮闭环运行（`d1…d2b` 为锚点轮，
`h20*` 为 H=20 方法轮）；**每轮 10 主阶段**，轮与轮之间只继承"上一轮最优 head"。
完整轮默认跑 **8.5 执行器适配**（`WITH_WBC=1`；启动器在**本轮主评测之后**执行，
命名 8.5 表示"joint 之后的执行器适配"，不计入 10 阶段验收）；
h20r2 的 8.5 产物 vA 与 v7 打平，部署仍用 v7；h20r3 为隔离 act_weight 显式 `WITH_WBC=0`。

| # | 阶段 | 输入 | 做什么 | 产物 | 门禁/断言 | 耗时 |
|---|---|---|---|---|---|---|
| 1 | `a_collect` | 冻结 WBC + 库 | 只跑 WBC、无 VLA 的向量化物理采集；按"物理退化"过滤（关节越界/倒地/NaN）并记录每条轨迹有效长度 | `ac_w*.pt`（24 片 × 153.6k = **3.68M 行**；`valid_len` 合计 ≈**2.34M 有效**） | A 线已存在则跳过；少于阈值则重采 | ~8 min |
| 2 | `collect` | 上一轮 head | VLA 在环闭环采集（6 任务 × 7 集 × 600 tick；**600 是 cap，参考 clip 中位 789、80.5% >600**），从库帧随机起点初始化 | `runs/B_<R>/`（42 集） | **必须采满 42 集**（≥41）才继续，否则清空重采 | ~45 min |
| 3 | `score` | B 线 dump | 全池打分（bundle 只加载一次） | `<ep>/scored.pt` | 打分数量 == dump 数量 | ~15 s |

| 7 | `critic_gate` | 本轮转移 | 裁判门：`imagined` 源放行；`real` 源要求留出 `v_ev > 0.30` | `critic_gate.json` | 门说不过 ⇒ 两臂强制 `critic=OFF` | ~10 s |
| 8 | `joint` | WM + B 线 + self 真值 | **联合微调 200 次 optimizer updates**（有效 batch 64；8 卡 DDP 或 4+4；细节见 §6）；开训前按门结果定 `act_weight` / `yaw_rate` / 新数据权重 | `runs/S3_loop/<R>_joint/` | 断言：训练用的 WM == 阶段6 的产物；`joint 生效值`（act_eps/act_w/yaw_rate/fresh glob）== args.json；奖励项与设定一致 | ~15–20 min |
| **8.5** | `wbc_adapt`（**可选，完整轮默认开**） | 本轮 joint 的 VLA + B 线 + 本轮 WM（gate 产物） | **Path A（`plain`，默认）**：VLA 冻结，只训 WBC（`unfreeze=all`，lr 1e-6，200 步，**无 KL**）；**Path B（`joint_kl`）**：VLA+WBC 联合（`dec`，FM 1e-5 / WBC 5e-7，WBC action KL=0.5，VLA token KL=0）。**执行时机：本轮主评测之后**（主评测仍用上一轮执行器），胜者作为下一轮/部署的执行器候选（需显式设 `EXECUTOR`） | `runs/S3_loop/<R>_wbc[_kl]_joint/train_main/joint_final.pt`（即 vA/Flow B 执行器） | Path A 后 VLA 参数逐位不变；Path B 必须 WBC KL>0；8.5 的 base vs new 同 VLA 32 集，**mean<0 且 median<0 才换执行器**（只赢尾部不换） | ~8–12 min |

**Algorithm 1（单轮 $k\to k+1$，10 个主步 + 可选 8.5）**

```
输入：上一轮 head π_k，动作库 ℳ，冻结执行器 W，A 线（已有）
1  a_collect    : 采集 A 线（仅 W，无 π；向量化物理）        →  满足行数即跳过
2  collect      : π_k 在环采集 B_k（6 任务 × 7 集）           →  必须 42 集
3  score        : 对 B_k 每个重规划时刻算 e_inst、realized_err
4  transitions  : 建真转移 (s,a,s′,r)；同时导出"执行 token"作自监督真值
5  wm_refresh   : 三阶段训练 f_θ：A 100% → A:B=1:1 → k=20 自回归   (式 9)
6  wm_gate      : 三栏验收（多步 / 一步 OOD / in-dist 角速度）      (式 10)
7  critic_gate  : 判 V 是否可信（imagined 源放行，real 源要求 v_ev>0.3）
8  joint        : 从 π_k 起，想象反传 200 次 updates（有效 batch 64）；λ_r=0.3、
                  act_weight 由课程定（h20r2=0.5；h20r3 试 0.25 未赢）；β、w_ψr、新数据权重由门定
                                                                (式 1–8)
8.5 wbc_adapt   : 可选（完整轮默认开；启动器在阶段 10 后执行，胜者作下一轮执行器候选）；
                  Path A 冻结 VLA、只训 WBC（无 KL，vA）；Path B 为 VLA+WBC 联合 + WBC KL=0.5（Flow B）
9  eval         : 32 集配对闭环（同场、同 reset seed），π_{k+1} vs 上一轮最优  (式 11)
10 report       : 配对差 / CI / 中位 / p90 / 摔倒率；独立验收器复核配置一致性
```

## 5. 方法创新点

> 只写**方法/架构层面**的设计，且每条都有"为什么这样设计"的机理与"有没有效"的实测。

### I0｜**想象视界对齐执行窗口：H=20**

**设计**：token 每次输出 40 步，但执行端每 **20 步**重规划一次（20 步 hold 块，块内 token 不变）。
训练时的可微 rollout 视界取 **H=20**，正好覆盖"策略真正被要求负责的那 20 步"。
旧版 H=8 只覆盖 40%，后 60% 的执行误差在信用分配里是"无人负责"的。

**机理**：H=8 时奖励只对前 8 步负责，后续漂移不受惩罚；而闭环误差的绝对量主要在后段
（d2b 后 100 步 0.29 m vs 前 100 步 0.09 m）。把 H 拉到 20 让"后段"进入梯度，
且不需要把 WM 推到 k=40（WM 在 k=40 的 root 误差 12.8 cm，已经不可用）。

**证据（同一 d2b 起点、同一冻结 WBC、配对闭环）**：

| 臂 | H | act_weight | n | 配对差 vs d2b | 95%CI | 更好 |
|---|---|---|---|---|---|---|
| P0 | 20 | 1.0 | 32 | **−0.95 cm** | [−1.55,−0.27] | 28/32 |
| B | 20 | 0.5 | 16 | **−1.36 cm** | [−2.05,−0.74] | 14/16 |
| AB | 20 | 0.5（λ_r=0.6） | 16 | +1.08 cm | [−2.15,+5.27] | 10/16 |

* P0 后段 −1.68 cm、最后 50 步 −2.10 cm；B 后段 −3.52 cm、最后 50 步 −5.46 cm；
* **B vs P0 直接配对（同 16 集）：−0.90 cm，CI [−2.32,+0.34]，差中差 −0.52 cm** ——
  点估计更好但 **16 集不可分**，只能说到"~1.6× 点估计放大"，不能声称显著；
* **归因边界**：H=20 同时把奖励项影响力放大 ~2.5×（`imag_ret` 按 20 步累加），所以 P0 是
  "**覆盖 + 影响力**"的联合效应；要单独看覆盖需 P1（λ_r=0.12 折回 H=8 影响力），本轮未跑；
* **H 不是越大越好**：k=40 的 WM root 误差 12.8 cm（k=20 为 3.8 cm），且执行窗口只有 20 步；
* **λ_r 不能跟着放大**：0.6 出现 +26 cm 的灾难集，0.3 是稳定点（见 I4）。

### I1｜面向想象奖励的世界模型训练配方：**双源数据 + 三阶段课程 + k 步自回归**

**设计**
* **双源**：`A 线`＝只跑冻结执行器、无 VLA 的向量化物理采集（学"机器人自身怎么动"）；
  `B 线`＝VLA 在环的闭环采集（学"部署时怎么漂、怎么接触"）。
  **不混入参考动作库**：参考库提供的是"录制轨迹的连续性"而非部署动力学，混进来会把 WM
  拉向参考域（实测表现为"刷新后对录制语料退化、对本轮分布变好"）。
  配比显式给定：`阶段1 = A 100%`、`阶段2/2b = A:B = 1:1`（**B 占整批 50%**）。
* **三阶段课程**：① A 线单步 3000 步 → ② A+B 混合单步 3000 步 → ③ **B 连续窗口 k=20 自回归
  1500 步，每步交织一条 A 线单步样本**。
* **角速度通道加权**：WM 的损失里 `v / w / qd` 原本**三项等权**，而 `w`（root 角速度）只有 3 维、
  `qd` 有 29 维 ⇒ 角速度被挤掉。故用 `w_lambda`（默认 3.0）单独抬高 `w` 的权重。
* **门（三栏）**：① 多步 in‑dist（当轮同分布留出，k=1/5/10/20，≤1.05× 上一版）作**准入**；
  ② **一步 OOD**（录制语料 `qd_corr`，不得低于基线的 0.9×）作泛化监测；
  ③ **root 角速度**（**in-dist** 决定 `yaw_rate` 能否启用；OOD 栏同时量 `root_w_corr` / `root_w_ratio` 作监测）。

**机理（为什么必须这么做）**
* 只用录制的参考轨迹训练时，WM 学到的是"参考轨迹的连续性"而不是动力学：
  同一模型在运动学参考上单步速度相关 `qd_corr=0.9689`，在真物理数据上只有 **0.4976**（`qd_ratio` 1.21）。
* 前两阶段的损失是**纯单步**（输入永远是真实状态）⇒ 模型从没见过自己的输出，累积误差完全不受约束：
  单步训练后 k=1 的 `qd_ratio` 1.00，k=20 却是 **1.31**。
* 自回归阶段必须**交织真实单步样本**，否则会打坏前两阶段的单步精度（实测纯 B 窗口 600 步即可打坏）。

**测量口径（必须钉住）**：多步评测喂给 WM 的动作**与训练同源**（dump 里的 `actions`，
即策略原始输出）。等价性是可验证的：`q_target − default_q` 与 `actions` 相差 4 倍、逐元素差
最大 9.5 rad（因为 `q_target = clip(q₀ + a·scale)`，`q₀` 是当时的关节位置而非 `default_q`），
两者不可互换；口径不一致会让误差被系统性低估。

**效果**（in-dist 留出；H=20 配方 vs 旧 WM）：

> 前四行是**当轮 SitSofa 同分布留出的相对门读数**；下面 134 固定留出是**独立复测**，两套不可混比。

| 视界 | 关节 RMSE 相对旧 WM | root 相对旧 WM |
|---|---|---|
| k=1 | −10.5% | −6.8% |
| k=5 | −5.4% | −6.1% |
| k=10 | −4.6% | −5.5% |
| k=20 | **−4.1%** | **−7.5%** |

固定 134 留出集上，k=20：关节 **0.066 → 0.061 rad（−7.2%）**、root **4.1 → 3.8 cm（−8.9%）**、
姿态 7.3° → 7.7°、`qd_corr` 0.555 → 0.542、`root_w_corr` 0.498 → 0.470
（这是固定 134 留出；不是 §7 的 yaw 门——后者 in-dist k=5 为 0.695）。
即：**长视界的收益主要在 root 与关节；姿态没有变好（略差 0.4°）**。
奖励使用的视界是 **H=20**，对应 root ≈3.8 cm、姿态 ≈7.7°。
`qd_corr` 仍在 0.54 左右，说明 20 步后的速度通道仍偏弱。

### I2｜按**可观测性**分解奖励：root 朝向拆成 tilt / yaw / yaw_rate

**设计**：把"整块 root 朝向误差"按**策略能否观测**拆成三项，权重按可观测性并**按实测信号占比**给：
`tilt 0.2 : yaw 1.0 : yaw_rate 0`。三者的 σ 分别标定为
`tilt 0.25 rad / yaw 0.25 rad（近场）+ hinge 管远场 / yaw_rate 1.0 rad/s`。

**机理**：token 按定义是**相对当前朝向**的（`anchor = rot6d(q_robot⁻¹ ⊗ q_ref)`），且
`proj_grav` 对绕世界 z 的旋转不变 ⇒ **绝对 yaw 对策略不可观测**（视觉通道 token→yaw 的 R²≈0.23）。
把满权重压在不可观测量上，只会制造一个**不可学的常数项**，稀释真正可学的梯度。
因此拆项之后还要解决"yaw 到底能不能看见"：靠 I7 把**相对开局的旋转**送进 state；
而**相对参考**的误差在部署端拿不到（报文不含参考帧），仍属于局限（§9）。

**标定依据（按"每一项在真实数据上产生多少信号"定权）**：三项在 B 线数据上的贡献为
`tilt 27.1% / yaw‑exp 37.8% / yaw‑hinge 35.2% / yaw_rate 0`。
关键机制：**σ 与权重必须分开标定**。σ 决定"够不够得着"——σ=14° 面对 37–57° 的真实 yaw 误差时
`exp(−(37°)²/0.25²)=1.2e-3`、均值处 `1.3e-7`，该项实际已饱和（只占 5.3%），此时加权重无效；
权重只在 σ 匹配误差量级之后才有意义。

> 注：H=20 locked 轮把 **yaw-hinge 置 0**（见 I3 / §10），所以上面的 35.2% 是
> **标定依据**，不是当前主结果配置的权重；yaw-exp 1.0 保留。

### I3｜**两段式奖励核**：`exp` 主体 + `hinge` 尾部（梯度覆盖设计）

**设计**：主体仍是 `exp(−e/σ²)`（小误差区精度好），额外加**只在尾部生效的线性铰链**：
`λ·relu(‖Δp‖−0.35 m)`（cap 1.0 m）、`λ·relu(θ_tilt−20°)`（cap 57°），`λ=2.0`。

**机理**：`exp` 核的梯度是 `−2e/σ²·exp(−e/σ²)`，**两端都趋 0**。在闭环数据上实测：
`e<0.1 m` 的时刻占 **72.4%** 却提供 **86.3%** 的位置梯度；`e>0.4 m` 占 **21.2%** 只提供 **0.22%**。
于是纯 exp 目标的**最优解就是"拿尾部换中位"**（中位变好、p90 反而翻倍）。
铰链在 `0~e₀` 恒 0（不抢主体梯度）、`>e₀` 线性（补死区）——这也是为什么选 hinge 而非 MSE/Huber：
后两者在主体区间与 exp 完全重复。

**两处实现细节**
* **越过 cap 后必须保留斜率**：`clamp(max=cap)` 会让"烂到没边"的样本梯度恒为 0
  （覆盖 B 线 52% 的时刻），故用 `min(x,cap) + slope·relu(x−cap)`（`--tail-cap-slope`，默认 0.5）。
* **yaw 也适用"近场 exp + 远场 hinge"**：误差中位 37°、p90 143°，`exp` 早已饱和，
  故远场由 `λ·relu(|Δyaw|−15°)` 承担（`λ=0.3`、cap 60°、远端坡度 0.5），
  梯度实测 `[1.0, 0.5]`（中位/p90 处均 >0）。
  **但 H=20 locked 主结果把 yaw-hinge 置 0**：它是独立旋钮，locked 轮显式
  `YAW_HINGE_LAMBDA=0`（保持单旋钮）。yaw-hinge **不靠 root_w 门自动启用**——门控的是
  yaw_rate；要开它必须单独做消融。
* **一个必须写进论文的负结果**：对**配对比较**而言，任何**单调核变换都不能提高信噪比**——
  它按同一比例放大信号与噪声。因此"把核调陡"救不了分辨率；能救的只有
  **换读出量**（如直接用 root 漂移）、**降噪**（配对基线 / 更多窗口）与**扩大可观测性**。

**效果**：p90 **0.339 → 0.191（−44%）**，单集方差 sd **0.091 → 0.033**。

### I4｜以**执行结果**为锚的自模仿信任域（不需要标签）

**设计**：token 空间的信任域中心 = **采集时策略自己真正下发的 token**，而不是数据集标签、
也不是"上一轮策略的输出"。度量 `relu(RMSE(token, self_prior)/eps − 1)²`，`eps=0.2, w=1.0`。
每个重规划时刻同时记录**真值** `realized_err`（随后 20 步的实际根位漂移），可做优势过滤：
只在"实际走得好"的时刻做自模仿。

**机理**：实测发现**任何"往参考 token 拉"的监督都会让闭环变差**——因为参考 token 对"已经漂了的
状态"不是纠偏方向；而奖励项经 WM 想象、分辨率有限（见 I5）。B 线 dump 里恰好有监督所需的真值，
于是把自模仿限定在"自己的输出、且实际执行得好"的样本上：既不朝错误方向拉，也不依赖裁判。

**效果**：`eps` 被置 0（该项等于关闭）时不生效；开启后
`trust/rmse 0.138 → 0.097`、`act/rmse 1.152 → 0.533`。

**四点实证（H=20 下重测）**
* **降 act_weight 是放大器**：同一批 16 个 seed 上，P0（act_w=1.0）−0.84 cm、B（act_w=0.5）−1.35 cm
  对 d2b；B 后段 −3.52 cm、最后 50 步 −5.46 cm。说明"放开锚点"让策略能补偿执行器漂移。
  （早期 `c1–c10` 只有奖励、动作球不触发时闭环结果随机；`trust_center: prev→self` +
  `act_eps 0.3→0.6` 才把闭环拉进单调变好——这段历史结论仍成立，但幅度被 12 集口径高估。）
* **不能靠加 λ_r**：AB（λ_r=0.6 + act_w=0.5）均值 **+1.08 cm**、`frac_out=0.51`、含 +26 cm 灾难集
  ⇒ 0.6 是悬崖；λ_r 固定 0.3，收益只能从"放锚点"来。
* **锁定版固定 0.5**：`h20r3` 已跑完 0.25 固定臂（32 集）：**+0.02 cm、CI [−2.38,+2.06]、14/32**，
  不显著 ⇒ **0.5 是下界，0.25 不采纳，课程不启动**。
* **（原计划）只有 0.25 稳定且更好，才引入课程 0.5→0.25**，且必须带**双闸门**：
  训练内 `frac_out<0.45`、`L_fm` 不比上一档差 10%、无 NaN；**闭环**每降一档前用 32 集配对确认没变差。
  本次 0.25 未通过，双闸门未触发。
  旧 pipeline 的自动规则 `frac_out<0.35 ⇒ ×0.5` **不作为锁定方案**（h20r2 的 0.369 不会触发，
  h20r3 用显式 schedule）；**退场只能降 `act_weight`，不能降 `act_eps`**——eps 变小只会让球更紧。
  `act_eps` 保持 0.6 不动；`yaw_rate` 项另设 `root_w_corr ≥ 0.40` 且 `ratio ∈[0.85,1.15]` 的门。

### I5｜**裁判可用性判据**：想象奖励的"分辨率地板"

**设计/结论**：给出"学习式模型能不能当奖励"的三条判据 ——
① 留出集上 critic 的 `v_ev`；② **回报分辨率 vs 待分辨效应量**；③ 单步口径与多步口径必须分开量。

**机理与实测**：在固定 32 窗口评测集上，**策略与 GT 的想象回报真实差只有 +0.0019 m**，
而估计器噪声为 `±0.047/√N`（N=32 时 ±0.0083）⇒ **信号本身低于裁判的噪声地板**；
要分辨它需要 `v_ev > 0.998`，而离线监督式 critic 实测只有 0.088~0.152。
直接后果：训练 200→600 步时（旧协议），想象回报几乎不动（0.0272→0.0271），而 `boot` 项从 −0.069 涨到 +0.044
—— 优化器在优化裁判而不是奖励。据此我们把 critic 门写成流程里的硬门。

**这条结论的适用范围（**重要**）**：它限制的是**"用想象回报去裁决/选择策略"**
（例如"不跑闭环、直接用想象挑 head"），**不限制 pathwise 反传求梯度**。
两者要的东西不同：反传需要 `∂r/∂token` 的**符号正确、幅度可用、无系统性偏差**；
裁决需要**效应量大于裁判噪声**。训练并不需要"分辨两个策略 2 mm 的差"——
实证：`imag_delta≈0.002`（读不出差异）的同一批轮次里，闭环仍单调变好到 −0.123 m / 12-of-12
（12 集历史口径；现以 32 集复核）。
因此"只奖励训练（c1–c10）无效"的正确归因不是分辨率，而是**项级标定失败**：
yaw 项 σ 与误差不匹配（占 5.3%、梯度≈0）、yaw_rate 项与参考无关（corr 0.005）、
位置核 52% 的时刻落在死区。

**三条必须先成立的前提（否则"分辨率不足"的结论会被测量污染放大）**
1. **度量必须可信**：若把多步 `rot_err` 写成 `acos(tr)`（正解 `acos((tr−1)/2)`），
   对小角度它恒为 0 ⇒ **"姿态预测很好"完全没有被测量过**。修正后手工 roll 实测：
   k=20 的 yaw 误差是 **2–10°**（不是 0）。任何"某个通道预测得很好"的说法都必须先过单测。
2. **项级死区/噪声**：回报是多项之和，其中 **yaw 项在 σ 下饱和（占 5.3%）、yaw_rate 项与参考
   相关性 0.005（滞后 −12…+20 帧全部 ≈0）**。这两项让"回报分辨不出策略差异"这一结论被放大：
   换成 `imag_state` 读数后，候选比 GT 差 **+3.7%**（而回报只差 −0.5%）。
3. **分辨率地板的正确表述**：20 步 root 误差 **3.8 cm** 而策略间逐窗差 **~2 mm** ⇒ 裁判误差
   约为待分辨效应的 **20 倍**；这决定了"单窗不可辨识、只能靠跨窗统计"。

### I6｜**测量协议**：32–48 集配对 + 自助 CI + 尾部指标 + 4 条 sweep 并行

**设计**：两策略**同场、同 reset 种子**各跑 **32 集**（做决策）；**12 集只作方向**——
12 集的 CI 半宽常在 1–2 cm，分辨不了 <1 cm 的效应。自助 95% CI（1000 次）
+ 中位差 + **p90 / 最后 50 步** + 翻倒率；判决规则**预注册**：
**均值配对差 <0、中位差 <0、核心任务中位不退化、95% CI 排除 0**，四条同时成立才算"显著更好"。

**并行**：8 卡上 **4 条 sweep 并发**（每条 2 卡：main + ctrl），各自独立端口；
32 集一轮约 25–35 min。评测脚本只杀自己的端口，避免并行 sweep 互杀。

**评测契约**：`DoubleDesk`，`START_FRAME=0`，`MAX_STEPS=300`，`--sample-avg 4`，`SRV_SEED=0`；
两臂同场、同 reset seed、同执行器；每条 sweep 8 集（2 卡 main+ctrl），4 条合并 32 集；
48 集则每条 12 集。

**机理**：实测单次会话噪声压倒效应 —— 同一个 π₀、同一个种子，两个场次的绝对漂移差 **14 cm**
（0.355 vs 0.214）。因此单集/单场比较无法判断 5~8 cm 级的方法差异，只能比**配对差**；
且绝对均值随 seed 集变化（h20r2+v7：seed0–11 ≈0.137–0.143，0–15 ≈0.149–0.155，0–31 0.1427），
**跨 run 的绝对均值不可横比**。

### 附：策略课程（工程上必要，方法上非核心）

* 起点**链式继承**（第 k 轮从第 k−1 轮继续）+ 本轮新数据采样权重 **×3**
  + 只用"奖励核还有梯度"的起点（瞬时根位误差 ≤0.3 m，`e>0.5` 处梯度≈0、占 52%）。
* 依据：同一批数据从 200 步加到 800 步（旧协议）只换来 **+1.1 cm**，而换一批新采数据换来 **+2.8 cm**
  ⇒ 每轮增益来自**新数据**，不是步数；H=20 locked 轮固定 200 次 updates（有效 batch 64）。

### I7｜**与部署协议逐位一致的观测扩维**：`rotlocal6`

**问题**：token 按定义是**相对当前朝向**的；`proj_grav` 对绕世界 z 的旋转**不变**；state 里既无
yaw 也无位置 ⇒ **偏航对策略不可观测**。实测：机器人绝对朝向与 yaw 误差的相关只有 **+0.166**；
在同一个绝对朝向区间（如 [−80°,−60°)，122 个时刻）里 yaw 误差从 **−155° 到 +44°** 都有。

**设计**：把 6 维 `rot6d(conj(heading(q₀)) · q_now)`（**相对本回合起始朝向的旋转**）写进 VLA state
的 **46–51 槽位**（零填充区），乘 6 个可训练缩放（初值 **1.0**）。

**为什么是这个量，而不是"绝对朝向"或"相对参考"**
* **绝对朝向**在不同回合里**语义不同**（每集随机起始朝向；单帧输入无法归一化）⇒ 病态；
* **"相对参考"**（`rot6d(R_robotᵀR_ref)`）需要在部署时知道参考帧，而闭环报文只有
  `图像 + state64 + 任务文本` ⇒ 训练有、部署无 = **train/test input skew**（模型会优先依赖它，
  抽走后在最依赖的地方直接崩）；
* 而 `rot6d(conj(heading(q₀))·q_now)` **已经在 `state64[:6]` 里**（HA 协议本就如此），
  开局恒为 identity、回合无关。我们把它**逐位对拍到 numpy 参考实现**（含 ±180° 绕回），
  因此**部署接口与主干权重都不需要变动**，且训练/部署口径**数学上同一个函数**。

**效果/证据**：与 yaw 误差的相关系数从 abs6 的 **+0.166** 提到 **+0.341**；
端到端冒烟 ckpt 内保存 `state_extra_mode=rotlocal6`、`scale=[1]*6`。
**方法教训**：先证明"线上协议里已经有什么"，再决定要不要改第三方——本例省掉了整条客户端改造。

### I8｜**会失败的测量门**：奖励活性审计 + 三栏 WM 验收 + "指纹==实际生效"

**动机**：这一版抓到并修掉的**静默失效**全部从"没人量的地方"漏过去——
`yaw` 项三轮里一直是死的（占 5.3%）、`yaw_rate` 项一直在奖励噪声（corr 0.005 at all lags）、
"新数据×3"从 d1 起就没生效（相对 glob 匹配绝对路径）、`rot_err` 恒为 0（`acos(tr)` 公式错）、
WM 刷新把 `root_w_corr` 洗坏（0.500→0.261）而门只看多步关节误差。

**设计（每条都能报红）**
1. **奖励项活性审计**（开训前，跑在真实 B 线数据上）：逐项报 贡献占比 / 核值 / **梯度**；
   低于阈值即中止。反证：`W_YAWRATE` 改回 0.3、或 σ 改回 0.25 却不加 hinge，**当场红**。
2. **三栏 WM 验收**：多步 in‑dist（准入）＋ 一步 OOD（`qd_corr`）＋ **root 角速度**（`root_w_corr/ratio`）。
3. **"指纹 == 实际生效"**：`verifier` 把日志里实际生效的参数（`state_extra / adv / tail_cap_slope /
   act_eps / yaw_rate / fresh glob`）与 `args.json` 逐项对齐，不一致即判该轮不合格。
   这条直接抓出了 `ROUND=99 X="$(f)" cmd` 的命令替换污染（helper 看到 ROUND=99 ⇒ 参数全跑偏）。
4. **口径标签**：所有仪器打印必须带 `data_source`
   （`recorded_npz(OOD)` / `B-line holdout (in-distribution)`），禁止跨源比较。
5. **A-order 自检**：WM 阶段1 必须 `--a-order declared`；脚本核对实际喂入顺序，顺序错整轮中止
   （曾因默认排序把 A 线顺序洗错而失败）。
6. **P 池删除**：扰动库（`Bw_pert*`）被证伪后从流水线移除（数据归档 `runs/_deprecated_pert/`），
   阶段 2b 不再要求扰动数据，`--mix-pert` 不再出现。
7. **DDP / 评测口径**：8 卡同一 init seed、rank0 广播 439 个可训练参数、`state_extra_scale` 参与
   all_reduce 与裁剪；评测只杀自己的端口；preflight 允许 fresh glob 为空（collect/all）。

### I9｜**8.5 执行器适配 track**：Path A（WBC-only）与 Path B（联合 + KL）的边界

**设计**
* **Path A（`plain`，完整轮默认 8.5）**：VLA 冻结（`FM_LR=0`），只训 WBC（`unfreeze=all`），
  **无 KL**（`WBC_KL_ANCHOR=0`、`VLA_KL_ANCHOR=0`），仍用完整联合损失（想象奖励 + 0.6 动作 hinge）
  ⇒ 只有 WBC 收到梯度；WBC lr 1e-6、200 步。
  产出 v7/vA 这类执行器；8.5 评的是 **base vs new（v8 vs v7）**，两条都用同一个 VLA。
* **Path B（`joint_kl`）**：VLA+WBC 联合（`dec`，`FM_LR=1e-5`、`WBC_LR=5e-7`），
  **WBC action KL=0.5**（VLA token KL 默认 0，失稳再加），200 步；即"一步式 Flow B"。
  Path B 的 VLA+WBC 联合解冻**必须带 KL**，否则 21× 崩；Path A 只解冻 WBC、VLA 冻结，可以无 KL。
* **Flow A**：先 joint VLA-only（主结果），再跑 8.5 Path A；评测是"同一 VLA，v7 vs vA"。

**结果（同一 VLA、配对闭环）**

| 方案 | 相对 | n | 配对差 | 95%CI | 更好 | 判读 |
|---|---|---|---|---|---|---|
| v7（8.5 Path A） | v6 | 32 | **−1.77 cm** | [−3.78,−0.18] | 17/32 | 尾部保险（27/32 核心中性） |
| Flow A（8.5 vA，Path A） | h20r2+v7 | 16 | −0.26 cm | [−1.57,+1.02] | 8/16 | wash |
| Flow B（Path B，joint_kl） | h20r2+v7 | 16 | +0.44 cm | [−0.41,+1.34] | 5/16 | 略差 |

**结论**
* 执行器/WBC 这条线**已饱和**：v7 的 −1.77 cm 几乎全部来自尾部（核心任务 27/32 中性），
  8.5 的 vA 与 v7 打平，Path B 的 Flow B 反而略差；
* **8.5 Path A 是完整轮的默认执行器适配（可选，但不改 VLA）**；它不是主收益，是尾部保险；
* **Path B（Flow B）不替代"joint + 8.5"**：一步式联合没有更好，且 VLA+WBC 联合必须带 KL；
* 主结果用**冻结 WBC**；部署主读数用 **h20r2 policy + v7**（vA 打平，仍选 v7）；
  h20r3 为隔离 act_weight 显式关掉 8.5。

**验收与依赖**
* P2 通过线：`(B 策略, v7) vs (B 策略, v6)` 32 集配对 **≤ −1.0 cm 且 CI 不含 0、零翻倒**；
  v7 实测 −1.77 cm、CI [−3.78,−0.18]，通过；但核心 27/32 中性，所以只作尾部保险。

  刷的，换 WBC 后必须**重刷 WM**；joint 阶段故意冻结 WBC 以保持单旋钮归因——这就是 8.5 必须
  独立成 track 的原因（§10.4 的部署主读数也因此是"h20r2 + v7"而不是"h20r2 自带 v7"）。

## 6. 联合微调（阶段 8）内部结构

### 6.1 损失组成

```
loss = λ_r · loss_r                       # 想象奖励（λ_r = 0.3）
     + w_act · loss_act                   # 动作 hinge（eps 0.6, w_act = 0.5；h20r3 试 0.25，未赢）
     + 0（token 信任域） + 0（λ_bc） + 0（λ_hand） + 0（posture）
# 可选 8.5 Path B（joint_kl / Flow B）：+ λ_wbc · MSE(a, a⁰)（λ_wbc=0.5）
#                                    + λ_vla · MSE(z, z⁰)（默认 0）
# 8.5 Path A（默认）：只训 WBC，无 KL
```

* 动作 hinge：`relu(RMS(a − a_exec)/0.6 − 1)²`，中心 `a_exec` = **真机实际执行过的 token**
  解码出的动作（同起点、同噪声）；`w_act` 从 1.0 退到 0.5（h20r2），h20r3 试 0.25（未赢）；
* token 空间信任域权重为 0（中心取 `self` 时它没有独立语义）；
* `λ_bc = λ_hand = 0`；posture 项已整体移除（绝对倾角/高度会与参考自身的倾身/下蹲冲突）；
* H=20 locked 轮的奖励里 **yaw-hinge=0、yaw_rate=0**（见 §6.3）；
* **8.5 两条路**：Path A（默认）VLA 冻结、只训 WBC、**无 KL**；Path B（Flow B）VLA+WBC、
  WBC action KL=0.5，VLA token KL 默认 0。

### 6.2 信用分配

```
s_t ──π_θ──► a_t ──可微 WM──► ŝ_{t+1},  t = 0..H−1，H = 20
ret      = Σ_{t<H} γ^t · survival_t · r_t
ret_exec = 同一起点、同一 τ 下"执行 token"的想象回报（无梯度）
adv      = ret − ret_exec                      ← 配对基线（控制变量）
boot     = γ^H · survival_H · ( V(ŝ_H) − V(ref_H) )
loss_r   = − mean( tanh( (adv + boot) / τ ) ),  τ = 0.02
```

* **配对基线**的作用：两个 rollout 共享"真机里真实发生的那一段"，把**窗口难度**这个公共大项减掉；
  实测把回报的跨窗标准差压到原来的 **6.4%**（`adv/std_ratio`）。
  注意它**不改变** pathwise 梯度的期望（减去的常数与动作无关），只降低估计方差；
* 分母 τ 把逐样本权重压成有界；当前分布下 `|adv| < τ` 恒成立，故该变换近似线性（等价的仅是
  逐样本重加权）；
* `V` 对 `ŝ_H` 保留梯度（straight‑through 0.1）；critic 用 GAE(λ=0.95) 在想象 rollout 上在线更新；
* **H=20 与执行窗口对齐**：token 每 40 步输出、执行端每 20 步重规划；H=20 正好覆盖一个执行块。
  H=8 只覆盖 40%（旧版），H=40 受 WM 误差限制（k=40 root 12.8 cm）不采用；H>20 收益递减
  而 WM 误差上升。

### 6.3 奖励

```
exp 主体：root_pos (w 1.0, σ 0.20 m) / tilt (w 0.2, σ 0.25 rad)
         / yaw (w 1.0, σ 0.25 rad) / yaw_rate (w 0 rad/s)
         / body_pos,ori 各 1.0（body 的 linvel/angvel 由 vel_scale=0 精确扣除）
         action_rate −0.1，joint_limit −2.0
yaw 远场：hinge λ=0.3（**可选；locked 主结果置 0**），relu(|Δyaw|−15°)（cap 60°，越 cap 保留 0.5 斜率）
hinge 尾：λ=2.0，relu(‖Δp‖−0.35 m)、relu(θ_tilt−20°)（cap 1.0 m / 57°，越 cap 保留 0.5 斜率）
```

三项权重按**信号占比**而非直觉给定：在真实闭环数据上实测为 tilt 27% / yaw-exp 38% / yaw-hinge 35%
（yaw 合计 71%）。但 **H=20 locked 轮把 yaw-hinge 置 0**：它是独立旋钮，显式
`YAW_HINGE_LAMBDA=0`。`yaw_rate` 权重为 0 是**显式 override**：in-dist 门其实过了
（k=5 `root_w_corr=0.695`、`ratio=1.021`，门自动给出 `W_YAWRATE=0.05`），locked 轮用
`YAW_RATE_WEIGHT_OVERRIDE=0` 压回 0；OOD `root_w` 仍差（corr 0.295、ratio 2.267，只监测），
所以也没有理由主动开。准入门槛写成 `corr ≥ 0.40 且 ratio ∈[0.85,1.15]`，由门自动判定。

> 尾部的必要性有直接测量支撑：`e>0.4 m` 的时刻占 21.2% 却只提供 **0.22%** 的位置梯度；
> 纯 exp 目标的最优解是"拿尾部换中位"。我们实测该形状把 p90 从 0.339 压到 **0.191**。
> （该形状本身来自 mjlab 线，见 §4；我们给出的是在本任务族上的独立复现与度量。）

### 6.4 训练数据与起点

* **起点链式**：第 k 轮从第 k−1 轮的 head 继续；
* **采样**：全池 + 本轮新数据权重 ×3；
* **起点筛选**：只用瞬时根位误差 ≤ 0.3 m 的重规划时刻（`e>0.5` 处奖励核梯度≈0，这类占 52%）；
* **观测**：VLA state 在 132 宽输入的 **46–51 槽位**填 `rot6d(conj(heading(q₀))·q_now)`（见 I7），
  6 个可训练缩放初值 1.0；
* **预算**：**200 次 optimizer updates**，有效 batch 64（8 卡 DDP：per-rank 8 × 8 × accum 1，
  梯度 `all_reduce(AVG)`；或 4+4），总样本 **12,800**；bf16，lr 3e-5；**H=20**；
  `act_weight=0.5`（h20r3 试 0.25，未赢）。

### 6.5 阶段 8.5：执行器适配（独立 track）

* **起点**：本轮 joint 的 VLA（`vla_final.pt`）+ 本轮 WM（gate 产物）+ 本轮 B 线 fresh；
* **Path A（`plain`，默认）**：VLA 冻结，只更新 WBC φ；损失同 §6.1 但 **无 KL**；`all`、lr 1e-6、200 步；
* **Path B（`joint_kl`）**：θ 与 φ 都更新；`dec`、FM 1e-5 / WBC 5e-7、**WBC action KL=0.5**、VLA token KL=0；
* **验收**：同一 VLA，base vs new 32 集，**mean<0 且 median<0** 才换；通过线 ≤−1.0 cm、CI 不含 0、零翻倒；
* **不变量断言**：Path A 后 action head 的 433 个张量与起点**逐位一致**；Path B 的 `dec` 之外 WBC 参数
  逐位不变；不一致即判该次 8.5 失败；
* **依赖/后续**：换 WBC 后 d2b/B/P0 的历史数字重测、WM 用 v7 数据重刷，再跑一轮锁定策略；
  8.5 因此不混进 joint 的单旋钮归因。

## 9. 局限性

1. **"相对参考"的朝向/位移仍不可用于部署**：`rot6d(R_robotᵀR_ref)` 需要参考帧，而闭环报文
   不携带它 ⇒ 只能用"相对开局的自转量"（I7）。要做到"与参考的误差"需在客户端补发参考帧
   （代码路径已留 `state_extra=ori6`），这会改变部署接口，本文不涉及；
2. **`yaw_rate` / `yaw_hinge` 暂时关闭**：`yaw_rate` 的 in-dist 门其实过了（k=5 corr 0.695、
   ratio 1.021，门自动给 `W_YAWRATE=0.05`），locked 轮用 `YAW_RATE_WEIGHT_OVERRIDE=0` 显式压回 0
   （单旋钮）；一步 OOD 仍差（corr 0.295、ratio 2.267，仅监测），所以也没有理由主动开。
   `yaw-hinge` 是独立旋钮，locked 轮显式 `YAW_HINGE_LAMBDA=0`，不受 root_w 门控；
3. **"分辨率地板"的结论部分依赖正确的度量**：修正 `rot_err` 的 `acos` 公式错误后，
   k=20 姿态误差是 **7.3°（旧 WM）→ 7.7°（新 WM）**，并没有变好；此前用错公式得到的"恒 0"
   不可用。任何"某个通道预测得很好"的说法都必须先过单测；
4. **绝对 yaw / 绝对位置对策略不可观测**（token yaw‑相对 + 93 维观测无位置/无 yaw）：
   * **纵向滞后**是系统性的（GT 臂 6/6 集同号，−5.7 cm）⇒ 可由策略学成"先验补偿"，**不需要新观测量**；
     `act_weight 1.0→0.5` 后 B 的后段已到 −3.52 cm，说明这份滞后正在被吃掉；
   * **横向**是逐集随机的（sd 6.3 cm、4/6 同号）⇒ 只能靠**位置反馈**逐集纠正，这是当前的结构性下限；
   * 因此"突破地板"要分两步：先靠继续降 `act_weight`（若 0.25 通过）吃掉系统性滞后，
     再靠加位置观测处理横向；
5. **执行器/WBC track 已饱和**：v7 的 −1.77 cm 几乎全在尾部（核心 27/32 中性）；8.5 的 vA 与 v7
   打平；一步式 Flow B 反而 +0.44 cm。8.5 Path A 只能当**可选尾部保险**，不是主收益；`act_weight=0.25`
   已测（h20r3：**+0.02 cm、CI 跨 0、14/32**），不赢 0.5 ⇒ **0.5 是下界**；
6. **A 线不含物体接触**（平地、无物体），接触部分只能靠 B 线吸收；
7. **评测噪声**：32 集配对的 CI 半宽仍有 0.6–2 cm，12 集只能作方向；绝对均值随 seed 集变化，
   跨 run 不可横比；每轮也只有单场评测，跨场结论依赖多轮累积；
8. **P 池是负结果**：扰动库（`Bw_pert*`）加入后没有带来可测收益，已从流水线删除；
   剩余误差仍以**系统性偏置**为主（集间常数占 23.5%），需要可观测性支持才能进一步抵消；
9. **H=20 的归因不纯**：它同时把奖励项影响力放大 ~2.5×（`imag_ret` 按 20 步累加），
   P0 是"覆盖 + 影响力"的联合效应；要单独看覆盖需 P1（λ_r=0.12），本轮未跑。
   另外 −0.95 cm 低于预注册的 1.3 cm 判据，论文里只能表述为"真实但不大"；
10. **P2 换 WBC 会破坏历史可比性**：WBC 是所有策略共享的，换后 d2b/B/P0 必须重测、WM 必须重刷；
    所以 8.5 只能作为独立 track，不能混进 joint 做单旋钮归因；
11. **`L_fm_val` 不可跨 DDP 度比**：DDP=8 是 64 个窗口、DDP=4 是 128 个窗口；只能在同一 DDP 度内
    看起点→终点的相对变化，绝对值跨臂比较会误导；
12. **B 线采集是 600-tick 封顶 + 长度偏置，不是全长**：参考库 699 个 clip 中 **80.5% 长度 >600**
    （median 789、p90 1431、max 10000）；B 线 collect 用 `START_FRAMES=random` + `MAX_STEPS=600`，
    且 `sample_start_row --margin=(MAX_STEPS+80)` 会先筛掉短 clip 和尾部：
    **Boxing 只有 19/100、SitSofa 52/100、PPBox 41/100** 条 clip 够长。所以策略池是
    "长 clip 的前 600-tick 段"，不是每条轨迹的全长。**直接改大 `COLLECT_STEPS` 不是全放开**：
    1500 ⇒ margin 1580 ⇒ Boxing/SitSofa 0 条可用，只会 fallback 到最长 clip 尾部。要真正全放开，
    需改采样器（起点在整条 clip 上均匀）+ 每条 `MAX_STEPS = length - start`（跑到 clip 末尾）。
    另外 `b_start_max_err=0.3` 会把"后续漂移 >0.3 m"的起点滤掉，长轨迹尾段本来也难进策略池。
    **Pilot（2026-11-01）**：Boxing 两条 clip（271 / 1564 tick），start=0、`MAX_STEPS=length`，
    dump 的 T 精确等于 clip 长度、数值有限；长 clip 可用起点 77 vs 短 13。说明"全放开"技术上可行；
    全量 699 clip 共 634k tick，按 pilot 吞吐估计约 3–10 h。

### 10.2 被替换、删除或澄清的旧说法

1. **"H=8"** → H=20。H=8 只覆盖执行窗口的 40%，后 60% 的漂移在信用分配里无人负责；
   H=20 是第一个在 32 集上显著优于 d2b 的配置（P0）。
2. **"800 步"** → 200 次 optimizer updates（旧口径 800 步 / accum4 的等价写法）。
   8 卡 200 updates × 有效 64 与旧 2 卡/4 卡语义一致；8 卡不是为了改 batch，是为了提速。
3. **"10 轮 × 10 阶段 ≈ 22 h"** → 每轮 10 阶段、8 卡约 1.5–2 h；平台按多轮跑，
   但"10 轮"不是方法的一部分。
4. **"12 集/臂"** → 32 集做决策（48 集更稳），12 集只作方向；判决需同时满足
   均值<0、中位<0、核心任务不退化、CI 排除 0。
5. **"yaw-hinge λ=0.3 启用"** → locked 主结果为 0；它是**独立旋钮**（不靠 root_w 门自动启用），
   locked 轮显式 `YAW_HINGE_LAMBDA=0`，不是当前配置的一部分（I2 的 35.2% 只是标定依据）。
6. **"执行器只能冻结"** → 主结果仍冻结，但完整轮默认 8.5 Path A（VLA 冻结、只训 WBC、无 KL，v7/vA）；
   Path B（VLA+WBC 联合）必须带 action KL，否则 21× 崩；Flow B 没有更好。
7. **"分辨率地板"的解读** → 结论保留，但**只限制"用想象回报裁决/选模"，不限制 pathwise 反传**；
   这次把边界写进 §9 与 I5，避免被误读成"训练没有梯度"。
8. **"P 池/扰动库"** → 负结果，删除；阶段 2b 不再要求扰动数据，`--mix-pert` 不再出现。
9. **"单场 12 集够用"** → 不够；32 集 + 4 sweep 并行 + 配对 bootstrap 才够分辨 ~1 cm 的效应。

## 附 B｜关键公式（论文 Method 用）

**记号**：状态 $s_t\in\mathbb R^{71}$（根位置/四元数/关节位置/根线速度/根角速度/关节速度），
动作 $a_t\in\mathbb R^{29}$，token $z\in\mathbb R^{64}$，执行器 $W$（冻结），世界模型 $f_\theta$。

**(1) 策略输入（观测）**
$$x_t=\big[\,q_t-q_0,\; \dot q_t,\; g_b,\; \mathrm{rot6d}\big(\bar R(q_0)^{\top}R(q_t)\big)\,\big]\oplus \text{hands},\qquad g_b=R(q_t)^{\top}\hat z$$
其中 $\bar R(\cdot)$ 只取 yaw 分量（heading）。最后 6 维使“相对本回合起始朝向的旋转”可观测；
开局恒为单位阵，故与回合无关。

**(2) 跟踪奖励（exp 主体 + 两段式）**
$$r_t=\underbrace{w_p e^{-\lVert\Delta p\rVert^2/\sigma_p^2}}_{\text{root 位置}}+\sum_{b}w_b e^{-e_b^2/\sigma_b^2}+w_\tau e^{-e_\tau^2/\sigma_\tau^2}+w_\psi e^{-e_\psi^2/\sigma_\psi^2}-\lambda_h\,\chi\!\big([|e_\psi|-\theta_h]_+;c_h,\beta\big)-\lambda_T\,\ell_T$$
$e_\tau$：把机器人与参考的 up 向量各转入自身 heading 系后的夹角（只含 roll/pitch，杜绝 yaw 泄漏）；
$e_\psi$：绕世界 $z$ 的 yaw 差。远场用 hinge 补坡，因为 $e^{-e^2/\sigma^2}$ 在 $|e|\gtrsim 2\sigma$ 处梯度≈0。
**locked 轮 $\lambda_h=0$**：yaw-hinge 是独立可选项，locked 轮显式关闭；root_w 门控的是 yaw_rate。

**(3) 带斜率的上限（消除“常量平台”）**
$$\chi(x;c,\beta)=\min(x,c)+\beta\,(x-c)_+$$
越过 cap 仍保留 $\beta$ 的斜率；$\beta=0$ 退化为 $\min(x,c)$，此时远场梯度恒为 0。

**(4) 动作锚（execution anchor）**
$$\mathcal L_{\mathrm{act}}=\Big[\tfrac{\mathrm{RMS}(a_t-a^{\mathrm{exec}}_t)}{\varepsilon}-1\Big]_+^{2},\qquad a^{\mathrm{exec}}=W(z^{\mathrm{exec}})$$
$z^{\mathrm{exec}}$ 是采集时**真机实际下发并被执行**的 token；同起点、同噪声。

**(5) 想象 rollout（可微）**
$$\hat s_{t+1}=f_\theta(\hat s_t,\hat a_t,\xi),\qquad \hat a_t=W(z_t),\qquad \nu_{t+1}=\nu_t\,(1-p^{\mathrm{term}}(\hat s_{t+1}))$$

**(6) 回报与配对基线**
$$G=\sum_{t<H}\gamma^t\nu_t r_t,\qquad H=20,\qquad G^{\mathrm{exec}}=\text{同一 }s_0\text{、用 }z^{\mathrm{exec}}\text{ 的想象回报（无梯度）},\qquad A=G-G^{\mathrm{exec}}$$

**(7) critic 自举（相对形式）**
$$B=\gamma^{H}\nu_H\big(V(\hat s_H)-V(\mathrm{ref}_H)\big)$$

**(8) 策略损失**
$$\mathcal L_\pi=-\mathbb E\big[\tanh\big((A+B)/\tau\big)\big]+\lambda_a\mathcal L_{\mathrm{act}}$$
注：$A$ 中的 $G^{\mathrm{exec}}$ 与动作无关 ⇒ 不改变梯度期望，只降低估计方差（实测跨窗标准差降至 6.4%）。
其中 $\lambda_a=w_{act}=0.5$（h20r3 试 0.25，未赢），H=20；λ_r=0.3。

**(8b) 可选 8.5 Path B 的 KL（Flow B）**
$$\mathcal L_{\mathrm{P2}}=\lambda_{\mathrm{wbc}}\,\mathrm{MSE}\big(a_t,a^0_t\big),\qquad
\mathcal L_{\mathrm{VLAKL}}=\lambda_{\mathrm{vla}}\,\mathrm{MSE}\big(z_t,z^0_t\big)$$
$a^0_t=W_{\phi_0}(z_t)$ 是**起点 WBC** 在同一 token 上的动作；$z^0_t$ 是同 obs/同噪声下
起点 VLA 的 token。Flow B 用 $\lambda_{\mathrm{wbc}}=0.5,\lambda_{\mathrm{vla}}=0$；
Path A（默认 8.5）只训 WBC、**不加 KL**；Path B 才开 $\mathcal L_{\mathrm{P2}}$（VLA+WBC 联合）。

**(9) 世界模型（三阶段 + 幅值标定）**
$$\mathcal L_{\mathrm{WM}}=\lVert\Delta p\rVert^2+\big\lVert\log(R^{\top}\hat R)\big\rVert^2+\lVert\Delta q\rVert^2
+\lambda_v\Big[\tfrac{\lVert\Delta v\rVert^2}{\sigma_v^2}+\lambda_w\tfrac{\lVert\Delta w\rVert^2}{\sigma_w^2}+\tfrac{\lVert\Delta\dot q\rVert^2}{\sigma_{\dot q}^2}\Big]
+\lambda_s\sum_{u\in\{v,w,\dot q\}}\Big(\log\tfrac{\overline{|\hat u|}}{\overline{|u|}}\Big)^{2}$$
前两项为半步显式积分：$\;p_{t+1}=p_t+\Delta t\,v_{t+1}+\Delta p$，$\;R_{t+1}=R_t\exp(\Delta t\,[w_{t+1}]_\times+\Delta\theta)$。
末项直接约束**幅度比**（$\lambda_w=3$，$\lambda_s=1$），抑制 L2 回归条件均值造成的幅值衰减。

**(10) 三栏验收（准入）**
$$
\text{(i) } \mathrm{RMSE}^{k=20}_{\text{joint}}\le 1.05\times\text{上一版};\quad
\text{(ii) } \mathrm{corr}(\hat w_z,w_z)\ge0.9\times\text{基线};\quad
\text{(iii) } \mathrm{ratio}=\tfrac{\overline{|\hat w|}}{\overline{|w|}}\in[0.85,1.15]
$$
(ii)(iii) 在**训练分布**上量（想象从 B 线状态出发）；录制语料上的单步 $q_d$ 相关性只作**泛化监测**。
`yaw_rate` 奖励项以 (ii)(iii) 为启用条件；WM 三栏准入的 `root_w` 用较宽的 `ratio∈[0.75,1.35]`，
yaw_rate 启用另用上式更严的 `[0.85,1.15]`。

**(11) 闭环判决量**
$$d_i=e^{\mathrm{cand}}_i-e^{\mathrm{base}}_i,\quad \bar d=\tfrac1n\textstyle\sum_i d_i,\quad t=\bar d/(s_d/\sqrt n),\quad \text{CI}_{95}=\text{bootstrap}_{1000}(\bar d)$$
