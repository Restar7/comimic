## 7. 补充：p20（新裁判 + 重标定 λ）——决定性结果

| 配方 | 新裁判下 λ_lim | 梯度占比 | test 越限率 | Gate P |
|---|---|---|---|---|
| **p19** | 0.0306794 | **250.7%** | **5.73%** | ❌ |
| **p20** | 0.00490（40% 预算标定值） | 40.0% | **5.80%** | ❌ |

两轮都是 300 步、`--init-lora` 从 C 基线出发、同一新裁判，**唯一变量是 λ_lim（差 6.3 倍）**。

### 结论（本轮最终）

> **在动作敏感的裁判下，物理越限率对 λ_lim 完全不敏感**（5.73% vs 5.80%）。
> 也就是说：**限位项（在想象状态上算的 L_lim）无法控制真机越限**。
> 旧裁判下看到的 2.75–2.85% 越限率，是"动作迟钝策略"的副产品，不是限位项起了作用。

### 现在的完整因果链

```
旧裁判对动作不敏感（误差只变 2%）
  → 策略拿不到动作相关梯度（所有 λ/奖励改动无效）
  → 且策略动作偏"迟钝"（因此越限低、看起来"安全"）

换成动作敏感的裁判（§3.3，误差↓28×）
  → 策略真正被优化，动作变激进
  → 真机越限率 2.8% → 5.8%
  → 而 L_lim 在想象状态上算，对真机越限不产生约束效力（λ 变 6.3 倍无差别）
```

### 因此

- **p19/p20 均未通过 Gate P，未进入闭环验证**；
- 想解决越限，必须换机制（真机约束、动作空间限幅、或把限位信号落到"转移可观测"的量上），**继续调 λ_lim 已无意义**；
- 交付物保持 `lora300_ddp`（sha `6942eab9`）不变；原 WM 未动（sha `8edb59cf`）。

## 9. 终局分析：为什么"把裁判修好"也没能让策略变强

**新裁判（p19 候选，误差↓28×、动作敏感）下的目标值对比**（48 个 Train 窗口，同一 token 采样种子）：

| adapter | 新裁判下的 J（均值） | 与 C 基线相比 |
|---|---|---|
| C 基线（旧裁判训的） | **+0.69697** | — |
| **p20**（新裁判微调 300 步） | **+0.69575** | **−0.0012** |

反推 pristine 底模（用 p20 的 `dJ_val=+0.00147`）：≈0.69428
⇒ **C 基线在新裁判下 = +0.0027 / p20 = +0.0015**，即 p20 反而略输给 C 基线。

**token 层面**：两个 adapter 的 token 差 \|Δ\|均值 0.0046，**相对幅度仅 2.89%**，cos **0.99956**。

### 三条判定

1. **目标动态范围过小**：J≈0.697，两个 adapter 的差只有 **0.1–0.3%**。这与仓库早先的结论"reward / kinematic 已饱和"一致 —— **不是裁判不准，是这个目标分不开策略**。
2. **微调几乎没动策略**：token 只变 2.89% ⇒ 闭环成功 13/16 vs 14/16、动作变化率 0.0987 vs 0.1000、越限两臂均 0%，全部无差别。
3. **因此"调参路线"走不通的根本原因不是 λ 选错、也不是裁判不准，而是目标函数的信息量/动态范围不足**。要产生可测提升，必须换信号源（闭环任务结果、成功率、进度），而不是继续打磨代理目标。

## 10. 新增能力：闭环数据现在带 **VLA 条件 token**（DAgger 的最后一块拼图）

**做了什么**（`scripts/wm_base6_record/sitecustomize.py`，两处）：

1. 每个 tick 记录 `tokens64 = provider._latest_vla_action[:64]`（取不到则 None，不阻断录制）；
2. `_flush` 把 `tokens64` 一起落盘（形状 `(n, 64)`）。

**验证**（Boxing seed2，400 步冒烟）：

```
tick 文件数: 16
tokens64: (16, 64) | 全非零 | 逐行范数中位=0.878 | 行间差异中位=0.0041
```

⇒ 从此每条闭环 tick 都是完整四元组 **`(state, token, action, next_state)`**，
这正是过去所有"闭环数据没法用来训练策略"的缺口（之前只有 state/action，没有条件输入）。

这是今天所有实验之后**唯一还带新信息的方向**；其余（λ、奖励形状、采样权重、换裁判）都已被数据否定。
