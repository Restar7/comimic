## 12. P6 的三项 loss 展开

按用户要求，P6 右侧三项 loss 从“一句话说明”改成 **公式 + 为什么用它**：

| loss | 公式 | 为什么 |
|---|---|---|
| ssm（权重 1） | `L_ssm = mean[((ŝ′−s′)/σ)²]，σ = max(std, ε)` | 71 维状态按各自尺度归一后一起优化；不归一化时位置（0.5 m）会把关节/速度淹没 |
| inc（×2.0） | `L_inc = Σ_b ‖(Δŝ′ − Δs′)/std(Δs′)‖²，Δ = s′ − s` | 动作对一步位置的贡献只有毫米级，按 0.5 m 归一后只剩 2.6e−6（等于没训）；换成增量尺度才可分辨，且增量里只有动作能解释 |
| gain（×2.0） | `L_gain = mean_b[(Δ_pred − Δ_true)²/std_b²]`，`Δ_pred = ŝ′(s,a_k) − ŝ′(s,a₁)` | A′ 里“同状态不同动作”的配对只有 2/60000，∂s′/∂a 没被约束（自由优化能降 89% 误差，但跨模型只转移 8%）；配对探针直接观测动作差 |


## 13. P9 显式展示 critic
